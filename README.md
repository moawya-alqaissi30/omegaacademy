# موقع OMEGA Academy

موقع تعليمي متكامل (Frontend + Backend) لأكاديمية OMEGA — بإشراف م. معاوية القيسي.

## المميزات
- تسجيل حساب جديد / تسجيل دخول (بكلمة مرور مشفّرة)
- حساب المعدل التراكمي (يضيف الطالب مواده وساعاته وعلاماته ويُحسب المعدل تلقائياً ويُحفظ)
- صفحة المصادر التعليمية (قابلة للفلترة حسب التخصص)
- صفحة البرامج التدريبية
- لوحة تحكم أدمن كاملة: إضافة/حذف مصادر، إضافة/حذف برامج، إدارة المستخدمين (ترقية لأدمن أو حذف)
- كل البيانات محفوظة في ملفات JSON داخل مجلد `data/` (قاعدة بيانات بسيطة بدون الحاجة لتثبيت أي برنامج إضافي)

## المتطلبات
فقط تثبيت **Node.js** (نسخة 18 أو أحدث) من الموقع الرسمي:
https://nodejs.org

لا حاجة لتثبيت أي مكتبات إضافية (لا Express ولا أي شيء) — كل الكود مبني بلغة Node.js الأساسية فقط.

## طريقة التشغيل (خطوة بخطوة)

1. افتح الطرفية (Terminal / cmd) داخل مجلد المشروع `omega-academy`
2. شغّل الأمر:
   ```
   node server.js
   ```
3. لما تشوف الرسالة:
   ```
   🚀 موقع OMEGA Academy يعمل الآن على: http://127.0.0.1:5500
   ```
   افتح المتصفح وروح على الرابط: **http://127.0.0.1:5500**

## حساب الأدمن الافتراضي
عند أول تشغيل، يتم إنشاء حساب أدمن تلقائياً:
- **البريد:** admin@omega.academy
- **كلمة المرور:** OmegaAdmin123

⚠️ **مهم جداً:** غيّر كلمة المرور فوراً — افتح ملف `data/users.json`، احذف حساب الأدمن، وسجّل حساب جديد من صفحة "إنشاء حساب"، ثم عدّل قيمة `"role"` بداخل `data/users.json` لتصبح `"admin"` بدلاً من `"student"` لنفس حسابك، أو اطلب مني لاحقاً إضافة صفحة لتغيير كلمة المرور من داخل الموقع.

## هيكل المشروع
```
omega-academy/
├── server.js          ← الخادم الرئيسي (Backend) وكل نقاط الـ API
├── db.js              ← إدارة قاعدة البيانات (JSON) والتشفير والجلسات
├── package.json
├── data/               ← قاعدة البيانات (تُنشأ وتُحدَّث تلقائياً)
│   ├── users.json
│   ├── sessions.json
│   ├── resources.json
│   ├── programs.json
│   └── gpa.json
└── public/             ← الواجهة الأمامية (Frontend)
    ├── index.html
    ├── login.html
    ├── register.html
    ├── dashboard.html
    ├── gpa.html
    ├── resources.html
    ├── programs.html
    ├── admin.html
    ├── contact.html
    ├── css/style.css
    ├── js/app.js
    └── img/logo.png
```

## كيف أرفع الموقع على الإنترنت (Hosting)؟
لما تجهز، فيه خيارات سهلة ومجانية للبداية زي: Render، Railway، أو Replit — كلها بتدعم تشغيل مشاريع Node.js مباشرة برفع نفس هذا المجلد. لما توصل لهذه المرحلة قلّي وبساعدك خطوة بخطوة حسب المنصة اللي بتختارها.

## أفكار للتطوير لاحقاً
- صفحة "تعديل الملف الشخصي" وتغيير كلمة المرور
- رفع صور/شعارات للمصادر والبرامج
- نظام بحث داخل المصادر
- إشعارات بريد إلكتروني عند التسجيل
- ربط الموقع بدومين خاص (مثال: omega-academy.com)
